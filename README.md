# ml-lab
This repository is for personal AI/ML practices.   
I started basic things and planned to be familiar with handling models. I have far more theoretical background than hands-on experience. So it focuses on implementing mini model in code level and then applying several methods to public model.

## specific flow
- Phase0: building local environment for AI/ML   
- Phase1: implementing ML theory with PyTorch   
- Phase2: making GPT myself   
- Phase3: using public model(modern LLM system)   
- Phase4: applying the things so far for research 
     
*Phase0-3 run sequentially; Phase4 in parallel with other Phase   
*Most code and document will be located in experiments/phase
